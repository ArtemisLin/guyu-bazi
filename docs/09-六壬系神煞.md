# 六壬/六爻系神煞（多太极点视角）

> 2026-07-31 · 用户要求自行检索六壬系神煞资料并接入。本文记录已实现项（含出处与交叉验证）与候选扩充池。

## 已实现（v0.4 起显示在「神煞总览」面板）

### 1. 岁前十二神（以年支起太岁，顺行）

顺序：**太岁 → 太阳 → 丧门 → 太阴 → 官符(五鬼) → 死符(小耗) → 岁破(大耗) → 龙德 → 白虎 → 福德 → 吊客(天狗) → 病符**（唐·李淳风《四利三元》体系）。每一地支都对应一神，面板对盘中每柱标注。

**交叉验证**：该轮转与问真自身的丧门（年支+2）、吊客（年支+10）、以及岁破=六冲完全自洽——内部黄金样本两例（卯年）分别验得时柱巳=丧门 ✓、月柱丑=吊客 ✓，与主流软件所标一致。

出处：[太岁十二星起例（知乎）](https://zhuanlan.zhihu.com/p/585546061)、[十二流年神煞解说](https://www.360doc.cn/article/78725320_1018866436.html)、[王亭之论岁前十二神](https://www.xuanmen.com.cn/archives/835.html)

### 2. 天马（以月支起）

诀：**正七午上、二八申、三九戌、四十子、五十一寅、六十二辰**（寅月午、卯月申、辰月戌、巳月子、午月寅、未月辰，循环）。面板显示本月天马所在支及盘中命中的柱。

出处：[大六壬起课方法（知乎）](https://zhuanlan.zhihu.com/p/667562824)、[六壬金口诀合用神煞](https://c.m.163.com/news/a/FAT98OAU05489X1M.html)

## 候选扩充池（已检索到、待逐个核准起法后接入）

来自[《大六壬神煞》（南离生）](https://www.jianshu.com/p/15af359214fc)、[《六壬指南注解·神煞卷》](http://ab.newdu.com/book/s199999.html)的目录：

- **月系**：月德（六壬版，正月起巳顺行）、生气（正月起子）、死气/死神、天诏（正月起亥）、墓门、成神、圣心
- **季系**：天目（春辰夏未秋戌冬丑）、游神（春丑夏子秋亥冬戌）——注意六壬四废与八字四废口径不同
- **日系**：文星、福星（六壬版，与八字福星贵人口径不同）、日盗
- **旬系**：旬仪（六甲旬首）、旬奇

> 处理原则：这些名目各文献口径差异较大，**每加一个都需要至少两处独立出处一致**才写入引擎；需要月将/占时的六壬神煞不适用于八字盘，不引入。用户可从上表点名优先加哪些。

## 视角分组说明

「神煞总览」面板把全部已实现神煞按起法分为：**年煞／季煞／月煞／旬煞／日煞／柱煞** 六组（一煞可多属，如天乙贵人年日双起），加上六壬两行。分组标签定义在 `bazi-core/src/shensha.ts` 的 `SHENSHA_GROUP`。
