# 持久化格式契约（写进用户 vault 的一切格式）

> 2026-08-18 立档（审查建议：格式迁移已发生过一次——tags→「标签」键，却没有一份枚举「写进用户笔记的到底有哪些格式、各自兼容承诺是什么」的清单）。
> **原则**：下面每一项都是「永久数据」——插件将来任何版本都必须能读旧笔记；改格式只能**加字段／加版本分支**，禁止静默改含义。改任何一项先改本文，再改代码，再补 smoke 回归。

## 1. 断案笔记 frontmatter

写入方：`apps/plugin/src/note.ts` `noteTemplate()`（首建，字符串手拼）、`updateBirthFrontmatter()`（改生辰，走 `processFrontMatter`）。
读取方：`birthFromFrontmatter()`（唯一入口；codeblock 处理器／右键菜单／命令／同生辰检测／批注跳盘全部经它）、`collectTags()`。

| 键 | 类型 | 写入 | 读取 | 兼容承诺 |
|---|---|---|---|---|
| `案例名` | string | 首建 | 不读（文件名为准） | 仅展示；经 `yamlStr()` 转义（普通名裸写；含「: 」「 #」引号反斜杠、首字符为 YAML 指示符、首尾空白、布尔/null/数字/0x/.inf 字面量时加双引号，v0.1.16 起） |
| `bazi.v` | number | v0.1.16 起写 `1` | **不校验**；缺失＝v1 语义 | 字段语义变化时 bump 并在 `birthFromFrontmatter` 按 v 分支迁移 |
| `bazi.date` | `"YYYY-MM-DD"` 公历钟表日 | 必写 | 正则校验，不合格返回 null（不猜） | 永久 |
| `bazi.time` | `"HH:mm"` 24 时制钟表时 | 必写 | 正则校验 | 永久；晚子 23 时按当天日期填（G1 契约） |
| `bazi.gender` | `"乾"`/`"坤"` | 必写 | 其它值返回 null | 永久 |
| `bazi.sect` | `"wenzhen"`/`"huanri"` | 必写 | 非 huanri 一律按 wenzhen | 内部键名不随 UI 文案（不换日/换日）变 |
| `bazi.place` | `"省·市·区县"`（JSON 双引号转义） | 选填 | 原样字符串（**渲染前必须 esc**） | 地名库匹配不上时改生辰弹窗警示、不改选则原值保留写回 |
| `bazi.lon` | number 东经 | 选填 | 非 number 视为无 | 有则真太阳时按它修正 |
| `bazi.dst` | `true` | v0.1.15 起选填 | 仅 `=== true` 生效 | 中国夏令时 1986–1991 钟表读数标志（docs/00 #72） |
| `四柱` | `"年 月 日 时"` 干支串 | 首建/改生辰 | **目前零读取方**（预留检索） | 只写不读；日主可由第三柱首字派生 |
| `标签` | string[] | 首建（可空 `[]`，每项经 `yamlStr()`） | `collectTags` 读 | **独立键，不与 Obsidian 原生 `tags` 混用**（用户裁决 docs/00 #71）；读取兼容早期误写的 `tags` 键 |

## 2. 笔记正文骨架

- 三个二级标题：`## 命主档案`／`## 人生节点`／`## 断语`（`noteTemplate` 生成；`appendAnnotation` 找 `^##\s*人生节点`，找不到则文末补节）。
- ```` ```bazi ```` 代码块：内容任意（说明文字），插件渲染成「打开盘面」按钮；**生辰单一来源＝frontmatter，块内容不承载数据**。
- 复诊分节：`### YYYY-MM-DD 首次` / `### YYYY-MM-DD 复诊`（`appendConsult`，同标题存在则不重复追加）。

## 3. 批注行（人机两读的持久格式，`apps/plugin/src/anchor.ts`）

```
- ⏱ 2026丙午｜小暑乙未｜8/2戊申｜申时 —— 批语文字
```

- 前缀 `- ⏱`（也接受 `*`）；锚段用全角竖线 `｜` 分隔，1~4 级：`YYYY干支`｜`节气干支`｜`M/D干支`｜`X时`；`——` 后为批语（多行压一行，段间 `；`）。
- 写：`formatAnnotationLine`；读：`parseAnnotations`（正则宽松：干支可缺、`M/D` 一两位数均可；**不合格式的行不解析、不报错、不改写**）；还原：`restoreDrill` 逐级降级（缺哪级停哪级）。
- 锚显示文案（先公历后干支、带虚岁）是**展示层**，可改；行格式本身不可改。虚岁基准＝`ChartResult.birthYear`（真太阳时年）。

## 4. 文件路径

`{settings.folder}/[子文件夹/]{文件名模板}.md`，模板占位 `{案例名}`，文件名非法字符 `\/:*?"<>|` 替换为 `_`。批注／重现／同生辰检测**按文件不按路径**——用户在文件树里拖动笔记不影响任何功能。

## 5. 插件设置 `data.json`（`apps/plugin/src/types.ts` `BaziSettings`）

| 键 | 默认 | 说明 |
|---|---|---|
| `folder` | `八字剧本集` | 断案笔记根目录 |
| `fileTemplate` | `{案例名}` | 文件名模板 |
| `trueSolar` | `true` | 真太阳时开关 |
| `sect` | `wenzhen` | 新盘默认晚子时规则 |
| `overviewFolded` | `true` | 神煞总览默认收起 |
| `panes` | `{chartFold,noteFold,aiFold:false, noteW:380, aiW:260}` | 三栏折叠/宽度 |
| `settingsVersion` | `1`（v0.1.16 起） | 设置格式版本（见下「加载」） |

加载：`sanitizeSettings()`（`types.ts`，纯函数、有 smoke）＝**白名单逐字段重建**：字符串空/非串回默认、布尔非 boolean 回默认、`sect` 非 `huanri` 一律 `wenzhen`、`noteW/aiW` 须为有限数且夹到 170–900、**未知键一律丢弃**（早期残留的 `verified` 等会被清掉——要往 data.json 存新东西必须先加进 `BaziSettings` 与本表）、`settingsVersion` 恒写 1（将来迁移按 raw 值分支）。保存 `saveSettings()` 原样写回整个对象。

## 6. 引擎输出（非持久，但两壳共同消费）

`ChartResult`（`packages/bazi-core/src/chart.ts`）不落盘、每次重算；但 `birthYear`（真太阳时年）是虚岁与批注锚的**唯一**出生年基准，两壳禁止再从输入日期取年。

## 7. 变更流程

1. 改本文相应表格（新增行标起始版本；语义变化必须 bump `bazi.v` 或 `settingsVersion`）。
2. 改代码：写入端＋读取端一起改，读取端保留旧版本分支。
3. `apps/plugin/tools/smoke.mjs` 加「旧格式仍可还原」断言。
4. docs/00 记一条决策。
